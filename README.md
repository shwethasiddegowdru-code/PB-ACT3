This repository contains my Programming Basics Activity 3 programs implemented in C, Python, and Java. The main objective of this activity is to understand the basic syntax, program structure, compilation, and execution of different programming languages by displaying the message "Hello World". This repository documents my practical learning and programming activities.
Programs are organized by programming language for easy understanding and execution.
## Files Included

- helloworld.c – Hello World program in C.
- helloworld.py – Hello World program in Python.
- helloworld.java – Hello World program in Java.
